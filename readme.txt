A minimal block theme that provides a clean foundation for modern WordPress websites.

== Description ==

Flexa is a lightweight block theme built for creators, businesses, and developers who value simplicity, performance, and flexibility. It stays out of your way so you can focus on building your site instead of removing unnecessary features.

Features include:

* Clean, minimalist layouts
* Full Site Editing support
* System font stack with no external font requests
* Responsive, accessibility-friendly design
* Multiple style variations
* Core templates for everyday websites
* Custom page templates for greater flexibility

Everything is intentionally minimal, giving you a solid foundation that's easy to customise and extend.

== Installation ==

1. Go to **Appearance → Themes → Add New**.
2. Upload `flexa.zip` or search for **Flexa**.
3. Activate the theme.
4. Open **Appearance → Editor** to customise templates, patterns, and styles.

== Frequently Asked Questions ==

= Does Flexa use external fonts? =

No. Flexa uses the native system font stack, so no Google Fonts or other external font requests are made.

= Is Flexa compatible with Full Site Editing? =

Yes. Flexa is a block theme built for the WordPress Site Editor.

= Can I use Flexa as a parent theme? =

Yes. You can create a child block theme and customise templates, styles, or patterns as needed.

= Does Flexa work with plugins? =

Yes. Flexa is designed to work with WordPress core features and most well-coded plugins.
